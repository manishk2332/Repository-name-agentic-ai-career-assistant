ℹ️ About the Project

Agentic AI Career Assistant is a browser-based career guidance platform designed to help students and job seekers prepare for software development careers.

The system combines multiple career modules into one platform. Users can analyze their resume, identify missing skills, discover suitable job roles, prepare for interviews, generate career roadmaps and get practical project suggestions.

The current version includes a free Demo Mode, so the core career features can be demonstrated without purchasing external AI API credits.
